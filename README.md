# PixelForge_groupe6_projet4_S5
PixelForge : Projet de site vitrine pour une agence de photographie, réalisé dans le cadre d'un atelier pratique. Ce site met en avant la maîtrise des fondamentaux du développement front-end, avec une attention particulière portée sur le design responsif grâce aux Flexbox, CSS Grid et aux Media Queries.
