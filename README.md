# PixelForge

Projet 3 - Portfolio d'agence créative

Thème

- Studio de photographie

Présentation

PixelForge est un studio de photographie fictif. Ce projet consiste à réaliser un site vitrine moderne présentant les services du studio, son portfolio, son équipe et un formulaire de contact, tout en appliquant les bonnes pratiques du développement web et de la collaboration avec Git et GitHub.
